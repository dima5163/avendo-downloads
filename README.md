# avendo-downloads

Public release assets for Avendo direct downloads (macOS DMG, Android APK).

Source code is **not** published here. Builds are produced from the private
`avendo-mobile` repository and uploaded as GitHub Release assets so that the
marketing site `avendo-app.com/download` can serve them anonymously.

See the [Releases](https://github.com/dima5163/avendo-downloads/releases) tab
for the latest direct downloads.
